C-03 · Visual direction for Playhoot

Three candidate identities, each rendered on the same three real screens — the public entry/home, a session lobby with the host directing, and the teacher dashboard — with the same content, so only the identity differs. Open each page; the mockups include live hover, press and idle animations (mascot blink and bob), so interact with the buttons. These files are design material only: nothing here is app code. Every direction is designed to meet the spec's requirements: own identity that does not read as AI-generated, professional enough to pay for, lively, animated vector mascot (P24§4), WCAG 2.2 AA contrast, and all assets producible as code (SVG/CSS/Lottie — P24§3).

A · Ink & Sticker — recommended

A tabletop-game box: warm paper, near-black ink, flat accent fills, 2 px outlines and hard offset shadows. Buttons physically press down; cards tilt like stickers. Distinctive, honest, playful and grown-up at once.

Recommendation

Direction A — Ink & Sticker. It is the only one of the three that is simultaneously distinctive (the outlined sticker language is not what AI tools or competitors produce), professional (the ink-on-paper base and strict structure read as deliberate design), and lively (hard shadows make presses and pops feel physical). It has the best accessibility posture — near-black on warm paper passes AA everywhere by construction — and the lowest implementation cost: flat fills, solid offset shadows and 2 px strokes are trivial to express as CSS tokens and to carry into SVG/Lottie assets, which also keeps AI-generated game art (P24§3) on-brand with cheap instructions ("flat fill, ink outline"). B is the safe second choice if A feels too bold; C is the most fun but the riskiest for dense teacher/admin screens and for AA contrast.
