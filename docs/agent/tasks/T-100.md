## Goal
Design everything H1 builds — transactional queue + DLQ, admin second factor, compliance core, minimal plan, minimal budget, notifications with email, analytics ingestion — as `planned` documentation data, and write the implementation tasks T-101…

## Deliverables
1. Tables, operations, lifecycles and flow steps in `planned` for: txqueue (package), identity admin second factor, compliance core, plan free limits, budget core, notifications, analytics ingestion; plus the H1 endpoints.
2. D-NN decisions for queue design, admin 2FA, budget admission; V defaults for the values the spec leaves open.
3. Task briefs T-101… and the H1 board in `PLAN.md`.

## Acceptance criteria
- `node tools/validate-docs.mjs` at 0; every H1 flow has real steps (no `touches` left in H1 scope).
- Each implementation task is self-contained: an Opus/Sonnet session can build it from the brief plus the site data.

## Out of scope
