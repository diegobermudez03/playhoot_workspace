# T-403 — Discovery catalog, taxonomy and the public reads

**Tier:** B (Opus · medium) · **Size:** L · **Repos:** backend · **Milestone:** H4 · **Requires:** T-402

## Goal
Give Discovery its backend: categories and tags as admin-managed vocabularies, the search over
approved snapshots with its filters, the usage-fed popularity, the public card read, the recently
played section, and the anonymous endpoints the server-rendered pages consume — plus the public
read of what a place asks for (closes the D-042 gap). P14§1-2, B: search and D-048/D-051 govern.

## Read first
- Site data: `game.game_categories` / `game_tags` / `game_taxonomy_changes` / `game_game_tags` /
  `game_usage_days`, the new `games` columns (`category_id`, `popularity_score`), the operations
  `game.search-discovery`, `read-public-card`, `read-taxonomy`, `admin-taxonomy`,
  `record-game-usage`, `update-popularity`, the changed `game-card` (category, tags, filters), the
  flows `browse-discovery`, `view-game-card`, `ingest-game-usage`, `review-queue` (its taxonomy
  joins), the changed `play.session.commit-start` (the game-usage enqueue) and
  `play.session.list-recent-games`, `compliance.read-place-requirements`, and every
  `GET /v1/discovery*` + `GET /v1/compliance/requirements` endpoint.
- `DECISIONS.md` D-048, D-051, V-13, V-14; P14§1-2 in full; D-010/D-014 (delivery types).
- `docs/definitivos/md/playhoot.md` "Búsqueda de juegos" (lines ~421-463) for the shape of the
  sections and the tag helper.

## What to build
1. **Taxonomy**: the three tables, the V-14 starter seed (10 categories, ~24 tags, names in
   es/en/pt — this task writes them), `read-taxonomy` (public and admin reads), `admin-taxonomy`,
   `GET /v1/discovery/taxonomy`, `GET/POST /admin/v1/taxonomy`. The working card gains category and
   tags (`PATCH /v1/games/{g}`, `game_game_tags`); `ListGames` gains the my-games filters.
2. **Usage and popularity** (D-048): the `game-usage` delivery type registered by the orchestrator;
   `commit-start` writes the task in the start transaction; `record-game-usage` upserts
   `game_usage_days`; the hourly `update-popularity` periodic task recomputes
   `games.popularity_score` (V-13).
3. **Search** (`search-discovery`): sections (popular, categories with samples) and the filtered
   search (text over snapshot names with a trigram index, one category, tags any/all, language,
   template-only), offered approved content only, ordered by popularity then recency, V-13 pages.
   `GET /v1/discovery` and `GET /v1/discovery/search`; `GET /v1/discovery/sitemap` for the host's
   dynamic sitemap section (D-051).
4. **The public card** (`read-public-card` + `view-game-card` flow + signed image URLs):
   `GET /v1/discovery/games/{gameUUID}`; statistics only from the V-13 threshold; credits from
   provenance rows (readable even before T-404 fills them); not-available answers for withdrawn,
   blocked, deleted or never-approved games.
5. **Recently played**: `play.session.list-recent-games`, joined into `browse-discovery` for signed
   callers, guests included.
6. **Place requirements**: `compliance.read-place-requirements` + `GET /v1/compliance/requirements`
   (anonymous, rules only — never declarations).
7. New identity operations in the catalog and its test (anonymous reads included). Migrations edited
   in place (taxonomy tables, new columns, trigram index — note `pg_trgm` needs `CREATE EXTENSION`
   in the migration). Site data → `implemented`; validator at 0.

## Acceptance criteria
- Backend checks green, walkthroughs included.
- Tests cover: search returning only offered approved snapshots (a withdrawn, blocked, deleted or
  working-card-only game never appears); each filter and the any/all tag modes; popularity ordering
  from seeded usage; statistics hidden below the threshold and shown with definition above it;
  taxonomy retire keeping references; usage idempotency by Session; recently played per caller;
  place requirements for a per-state country, an open country and an unknown one.
- Validator at 0; commit and push. Say whether the creator must recreate the local database.

## Out of scope
Templates and the quota wiring (T-404). The pages themselves (T-405). Teacher Discovery (H8).
